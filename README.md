# 📝 Gerenciador de Lista de Tarefas (To-Do List)

Aplicação de linha de comando (CLI) desenvolvida em Python para gerenciamento de tarefas diárias.

## 🚀 Funcionalidades
- **Adicionar tarefas:** Cadastro contínuo de novos itens.
- **Listar tarefas:** Visualização das tarefas salvas.
- **Remover tarefas:** Exclusão por número de índice.
- **Validações:** Tratamento para lista vazia e números inválidos.

## 🛠️ Tecnologias
- **Python 3**

## 💻 Como Executar
1. Certifique-se de ter o Python instalado.
2. Baixe ou clone este repositório.
3. Execute o arquivo principal no terminal:
   ```bash
   python main.py
